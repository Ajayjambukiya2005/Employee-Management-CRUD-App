# Employee CRUD App (React + TypeScript + Bootstrap)

## 📌 About the Project
This is an **Employee Management** CRUD (Create, Read, Update, Delete) application built using the following technologies:

- **React** – For building the User Interface (UI)
- **TypeScript** – For type-safe code
- **Bootstrap** – For styling and responsive design
- **LocalStorage** – For saving data locally in the browser (without a backend)

In this application, you can add employees (Create), view the list (Read), edit details (Update), and remove employees (Delete).

---

## 🛠️ Prerequisites
Before running the project, make sure you have the following installed on your machine:

1. **Node.js** (version 18 or higher) — Download from [nodejs.org](https://nodejs.org)
2. **npm** comes automatically installed with Node.js

To check if Node.js is installed properly, run these commands in your terminal/command prompt:
